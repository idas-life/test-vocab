      怎麼保存進度

      進度每答一題就自動存在這支手機裡，重新整理、關掉網頁都不會不見。照下面做，就不怕被手機清掉。

      iPhone／iPad
      1. 用 Safari 打開網址（用 LINE 或 IG 裡的瀏覽器打開的話，先點右下角選「用 Safari 開啟」）。
      2. 加入主畫面：點下方中間的分享按鈕（方框加向上箭頭）→ 往下滑選「加入主畫面」→ 右上角「新增」。
      3. 之後只從桌面的圖示打開。主畫面版和 Safari 版的進度是分開存的，混著用會以為進度不見了。
      4. 不要刪掉桌面上的圖示，刪掉會連進度一起刪。
      5. 每週備份一次：下方按「複製備份文字」，貼到 LINE 的 Keep 或「備忘錄」存起來。

      為什麼要加主畫面：iPhone 的 Safari 會清掉太久沒打開的網站資料，加到主畫面的不會。

      Android
      1. 用 Chrome 打開網址（從 LINE 打開的話，點右上角「⋮」選「用預設瀏覽器開啟」）。
      2. 加到主畫面：點右上角「⋮」→「加到主畫面」或「安裝應用程式」→「安裝」。
      3. 之後從桌面的圖示打開。Chrome 和桌面圖示的進度是同一份。
      4. 不要在 Chrome 設定裡清除這個網站的資料，也不要清除 Chrome 的「儲存空間」。
      5. 每週備份一次：下方按「複製備份文字」貼到 LINE Keep，或按「下載備份檔」存到手機的「下載」資料夾。

      雲端同步

      備份進度

      換手機、換瀏覽器，或清除資料之前，先備份；之後在新的地方還原，就能接著背。

      還原進度

      還原會取代這支手機上目前的進度。

      重新開始

      清掉分數、連續紀錄、程度測驗和每個字的進度。你自己加的字和設定會留著。
